Works with PrintStream 1.0.6 or later.

- The integration is now called PrintStream everywhere in Home Assistant, instead of PrintStream Bridge. Existing setups keep working with no changes.
- The AMS card can be titled with a short name ("AMS A"), a long name that starts with the printer ("Workshop X1C AMS A"), or your own title. Cards that already have a title keep it.
- The card editors work again on current Home Assistant releases: the printer card's title field is visible, and every content checkbox has its label.
- A sharper integration icon in Home Assistant 2026.3 and later.
- **Reconfigure** in an entry's menu changes its name, URL or access token. It replaces **Configure**, and leaving the token blank keeps the current one.
- When PrintStream stops accepting the access token, Home Assistant asks you to re-authenticate instead of retrying in the background.
- **Download diagnostics** gives you a file for bug reports, with the access token, serial numbers and addresses removed.
- PrintStream for Home Assistant now needs Home Assistant 2024.11 or later.
